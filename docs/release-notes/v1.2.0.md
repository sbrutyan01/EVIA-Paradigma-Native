# EVIA Paradigma Native 1.2.0

**AVR chips**: the blocks compiled straight to the flash of an ATmega8, ATmega16, ATmega32 or ATmega2560
(Arduino Mega), and written to the board, with no avr-gcc and no avrdude.

- **Target** in the toolbar: Linux x86-64 or an AVR chip, and the chip's **Clock** (16 MHz unless set).
- With a chip, the palette has the board blocks the chip runs: Pin Mode, Digital and Analog Read and Write (PWM),
  UART Open, Write and Read, Delay and Millis. Print and Input use the serial port at 115200 baud.
- **Build .hex** (F7) writes the program as Intel HEX and says how much flash and RAM it takes.
- **Upload** (F6) builds, writes it through the board's bootloader - STK500 v2 on the Arduino Mega 2560, Optiboot
  (MiniCore for the ATmega8, MightyCore for the ATmega16 and ATmega32) - checks every page, then shows what the
  program prints in the Output window; the Input field sends it lines. **Run → Chip Upload Settings...**: the port,
  or an ISP programmer through avrdude (USBasp, Arduino as ISP, AVRISP mkII).
- Numbers are IEEE 32-bit floats, in AVR assembly written by EVIA Paradigma Native; printed as Run prints them.
- Small enough for the ATmega8: blink with its prints is 5.5 KB of the 7.5 KB a bootloader leaves.
- **File → Open Example → AVR Chips**: blink, button, fade, analog meter, a class with a pin, UART echo.
- Command line: `--avr program.evia --chip atmega8 [-o x.hex] [--clock 8000000] [--upload /dev/ttyUSB0]`.
- **Updates from evia.am**: Help → Check for Updates, and a check in the background; from this version on, EVIA
  Paradigma Native updates itself (1.1.0 and older need this one installed by hand).
- CI: every board program on all four chips and the number programs on the Mega 2560 in simavr against the
  interpreter, thousands of random int and float results, and uploads through the real bootloaders in simavr.
