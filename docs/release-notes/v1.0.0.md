# EVIA Paradigma Native 1.0.0

The first release of **EVIA Paradigma Native**, a fork of [EVIA Paradigma](https://github.com/sbrutyan01/EVIA-Paradigma)
0.11.0: visual block programming compiled straight to executables, with no compiler, assembler or linker.

- **Build executable** (F7) turns the blocks into a Linux x86-64 program (a static ELF file of about 33 KB, system
  calls only); **Run executable** (F6) runs it, with Input typed under the output.
- The program behaves exactly as Run does: output, error messages, exit code, number formatting and reading.
- Safe and fast values, classes and objects, all flow blocks, Delay and Millis.
- No Language list, code window, board, phone or FPGA blocks: those are EVIA Paradigma's.
- Installers for Windows, macOS (Apple Silicon and Intel), Ubuntu/Debian and any Linux (AppImage); it installs next
  to EVIA Paradigma. Updates come as new installers (Help, Check for Updates).
- Checked on every push: every example and test program against the interpreter, 100,000 numbers against Java.
