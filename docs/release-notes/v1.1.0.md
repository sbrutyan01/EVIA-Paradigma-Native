# EVIA Paradigma Native 1.1.0

**Export App**: a program as an app to hand to other people, for any Linux on x86-64.

- **Export app...** in the toolbar, and **Run → Export App...** (Ctrl+Shift+E): the app's name, command, version and
  description, the forms and the folder.
- **The executable**: static, about 33 KB, nothing else needed on the other computer.
- **A portable .tar.gz**: the program, a menu entry, an icon, `install.sh` (for you in `~/.local` without root, or
  `--system` for everyone) and `uninstall.sh`.
- **A .deb** for Ubuntu, Debian and Linux Mint: `/usr/bin/COMMAND`, a menu entry and an icon.
- The menu entry opens a terminal (Print and Input talk through one) and keeps it open when the program ends.
- Everything is written by EVIA Paradigma Native itself, tar, gzip and .deb included.
- Command line: `--export-app program.evia DIR [--name ...] [--command ...] [--version ...] [--description ...]`.
- CI exports an app, installs it for a throwaway user, runs it, removes it, and unpacks the .deb.
