# EVIA Paradigma Native 1.3.0

**An RTOS for AVR chips**: a small preemptive real-time kernel in the native AVR compiler, used with the blocks
you already have.

- **A task is a class with a method named `task`.** Each one gets an object and starts before the main program,
  which is task 0. Fields `priority` (1-250, default 1) and `stack` (bytes, default 256) set it up.
- The highest-priority ready task runs; tasks of the same priority take turns every tick (1 ms). A task that never
  waits does not stop the others.
- **Delay** in a task sleeps only that task. **Print** and **Input** hold the serial port for a whole line, so lines
  from different tasks never mix.
- **The `Rtos` module** (`examples/modules/rtos.eviam`, File → Import Module...): `sleep(ms)`, `yield()`,
  mutexes `lock(m)` / `unlock(m)`, semaphores `signal(s)` and `wait(s, ms)` with exits `got` and `timeout`.
- Every task's stack is checked at each switch: an overflow stops the program with a message instead of a crash.
- Runs on the ATmega32 (about five tasks in its 2 KB) and the ATmega2560. Run in the editor runs the main program.
- Example: `examples/rtos/rtos_demo.evia` (a blinking LED, producer and consumer, a busy task, a mutex).
- CI: `scripts/check-rtos.sh` runs it in simavr on both chips and checks priorities, timing and the error cases.
