# EVIA Paradigma Native 1.4.0

**Claude Code in the editor**: a **Claude Code** tab beside **Output** runs [Claude Code](https://claude.com/claude-code),
Anthropic's AI coding assistant, in a real terminal.

- It starts in the open program's folder the first time you open the tab, so it can read and change the `.evia`
  files there. Colours, keys and the window size work as in any terminal.
- It finds the `claude` command on PATH or where its installers put it, or you pick the file. When Claude Code is not
  installed, the tab shows how to install it (`curl -fsSL https://claude.ai/install.sh | bash`, on Windows
  `irm https://claude.ai/install.ps1 | iex`).
- When Claude Code ends, the tab offers to start it again. Running or building a program switches back to Output.
- In Russian and Armenian too.
- New third-party component: pty4j (JetBrains, Eclipse Public License 1.0) with JNA, for the local terminal.
- CI: `scripts/check-claude-tab.sh` drives the tab on the real main window.
